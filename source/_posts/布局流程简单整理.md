**RunLoop = Main Run Loop + Update Cycle**

为了便于理解,可以将整个App的RunLoop看做是由以上两个阶段组成.  
App在Main Run Loop Update Cycle阶段, 如果需要重新绘制, 布局等等.会给对应视图做好标记,  
等到Update Cycle时会真正开始对视图进行修改.整篇文章也围绕着以上理解展开.  


## 布局

简单来说,就是视图在屏幕的位置和大小.

### layoutSubviews()

调整当前视图及所有子视图的位置和大小.

```
open func layoutSubviews() // override point. called by layoutIfNeeded automatically. As of iOS 6.0, when constraints-based layout is used the base implementation applies the constraints-based layout, otherwise it does nothing.
``` 

该函数会在layoutIfNeeded调用后, 自动被调用. 调用代价也比较昂贵, 不要显示调用该函数.

隐式触发的条件:

  * addSubview. 被add的视图, 容器视图及容器视图的所有子视图都会触发layoutSubviews
  * 视图的frame的size改变. 注意size的值必须有变化,否则不会触发. - (感觉不是绝对的, 试了下origin改变到一定程度也会触发)  
_注意, 视图的frame改变会优先调用其superview的layoutSubviews. 然后再调用subview的layoutSubviews_
  * 用户旋转设备
  * 滚动scrollView时scrollView及scrollView的superview会触发
  * 更新视图约束



### setNeedsLayout

标记当前视图需要重新计算布局, 函数会立刻返回, 但是真正生效需要等待更新周期的来临

```
open func setNeedsLayout()
``` 

### layoutIfNeeded

检查当前视图是否需要重新布局, 如果有系统立即触发layoutSubviews, 没有的话该函数没有作用.  
```
open func layoutIfNeeded()
```

## 显示

视图的显示包括颜色, 文本, 图片, 和core graphics绘制等.

### draw

类似于布局的layoutSubviews, 但不会触发子视图的draw. 同样也不要显示调用该方法.

```
open func draw(_ rect: CGRect)
``` 

### setNeedsDisplay

标记当前视图需要重新绘制, 函数立刻返回, 真正生效需要等待更新周期  
周期来临, 会遍历所有的subview, 决定是否调用draw, 如果只想绘制部分, 可调用相应的方法

```
open func setNeedsDisplay()
open func setNeedsDisplay(_ rect: CGRect)
``` 

## 约束

三个步骤: 更新约束, 布局阶段, 显示阶段(draw)

### updateConstraints

```
open func updateConstraints() // Override this to adjust your special constraints during a constraints update pass
``` 

### setNeedsUpdateConstraints

```
open func setNeedsUpdateConstraints()
``` 

### updateConstraintsIfNeeded

```
open func updateConstraintsIfNeeded() // Updates the constraints from the bottom up for the view hierarchy rooted at the receiver. UIWindow's implementation creates a layout engine if necessary first.
``` 

### invalidateIntrinsicContentSize

```
open func invalidateIntrinsicContentSize() // call this when something changes that affects the intrinsicContentSize.  Otherwise UIKit won't notice that it changed.
``` 

前三个函数的含义和布局的类似. 最后一个函数代表根据视图内容得到自然尺寸, 更新周期来临生效.

补充:

  * setNeedsUpdateConstraints会保证未来周期来临调用updateConstraintsIfNeeded时.一定会触发updateConstraints
  * setNeedsLayout会保证未来周期来临调用layoutIfNeeded时.一定会触发layoutSubviews
  * layoutSubviews调用时, 随后也会调用updateConstraintsIfNeeded.
